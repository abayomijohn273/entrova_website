# Entrova — Software Development Company & AI Studio

Marketing website for **Entrova**, a software development company and AI studio that designs, builds, and ships custom software and AI products for startups and enterprises.

Built with [Next.js](https://nextjs.org/) (App Router), Tailwind CSS, and GSAP.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Pages

- `/` — Home
- `/services` — Software development services
- `/ai-studio` — Entrova AI Studio
- `/work` — Case studies & products we've built
- `/process` — How we work
- `/about` — About the studio
- `/integrations` — Platforms we build integrations with
- `/book-a-demo` — Start a project / book a call
- `/terms-of-service` — Terms of Service

## Project Structure

- `src/app` — App Router routes and layout
- `src/modules` — Page-level modules and their sections
- `src/components` — Shared layout and UI components
- `src/styles` — Global styles
- `public/images` — Image and SVG assets

## Tech

- Next.js 14
- React 18
- Tailwind CSS 3
- GSAP (scroll animations)
- Swiper
